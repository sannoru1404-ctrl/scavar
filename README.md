# SCAVAR — Староречье, 2001

**Хардкорный PvPvE-шутер на выживание в постоянном мире.** Беларусь, 2001 год. Семь лет после ограниченной ядерной эскалации, три года после «Чёрного импульса». Вы — один из жителей Староречья: добываете снаряжение, торгуете в живом городе, рискуете ради добычи и пытаетесь не встретить того, кто опаснее волков.

> **Формула:** DayZ (постоянный мир, исследование, выживание) + Tarkov (сетка инвентаря, пробитие брони, зональные ранения, торговцы) + собственный лор.

**Версия документации:** 2.0 · **Дата:** 2026-11-01 · **Стадия:** pre-production · **Платформа:** Windows PC · **Движок:** Unreal Engine 5.8

## Статус

Любое утверждение «работает» требует лога сборки или теста ([08](docs/08_QA_AND_ACCEPTANCE.md)).

## С чего начать

- **Основатель:** прочитать [01](docs/01_VISION_AND_SCOPE.md), [03](docs/03_CORE_GAMEPLAY.md), раздел «Решения» в [10](docs/10_DECISIONS_AND_LEGACY_MAP.md) и утвердить/исправить ADR-001…ADR-022 и `[NEW]` в [02](docs/02_LORE_CANON.md).
- **Разработчик:** [06](docs/06_TECH_ARCHITECTURE.md), затем бэклог M0–M1 в [07](docs/07_ROADMAP.md#11-стартовый-бэклог-m0m1).
- **Claude:** [`CLAUDE.md`](CLAUDE.md).
