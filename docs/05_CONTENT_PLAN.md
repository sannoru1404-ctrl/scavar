## 6. Таблицы лута: принципы

1. Каждое здание и контейнер имеют **теги применения**: `farm`, `residential`, `industrial`, `medical`, `military`, `rail`, `storage`.
2. Предмет имеет теги и допустимые тиры. Пример: бинт `medical`, `residential`, R0–R3; АК-74 `military`, R3–R4.
3. Редкость определяется тиром (см. [03](03_CORE_GAMEPLAY.md#5-что-даёт-риск-награда-по-тирам)).
4. Плотность точек лута: R1 — 12 / км², R2 — 8 / км², R3 — 6 / км² (концентрированно в зданиях), R4 — 5 / км² (TUNABLE; финал после слайса).
5. **Не более 15% точек** в здании могут выдавать оружие; патроны — отдельные точки.
6. **Цель в слайсе:** игрок находит первое оружие за 5–10 минут и первый бронежилет не раньше второго часа игры.

## 7. Шаблон POI (чек-лист для каждого уровня)

| Геометрия | Блок-аут → арт-пасс; пути входа/выхода минимум в 2 направления; видимые ориентиры |
| Лут | Теги зданий, число точек, тест на соответствие тиру |
| ИИ | Зона, шаблоны групп, кулдауны |
| Звук и свет | Профиль амбиента, звуки окружения |
| Навигация | Указатели, надписи, знаки (на русском, период 2001) |
| Приёмка | Проходимость NavMesh, отсутствие застреваний, производительность, `AT-048` |

## 8. Источники ассетов и лицензии

1. **Fab/Marketplace-first.** Покупать и использовать готовое, переделывать минимально. Собственное моделирование — для ключевых силуэтов (оружие, персонаж, уникальные здания).
2. **Лицензионный журнал** — [`data/asset_licenses.csv`](../data/asset_licenses.csv). Каждый внешний ассет: источник, автор, лицензия, цена, дата, использование в проекте. Без записи нельзя коммитить.
3. **Бинарные файлы** (`.uasset`, `.umap`, `.fbx`, текстуры, аудио) только через Git LFS.
4. **Оригинальные реальные марки** (логотипы, бренды) не используются; снаряжение узнаваемо по силуэту, а надписи вымышленные.
5. **Ограничения:** ничего, нарушающего правила лора ([02](02_LORE_CANON.md#7-правила-для-авторов-и-ассетов)).
