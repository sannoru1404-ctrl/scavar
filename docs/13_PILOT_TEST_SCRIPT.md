# 13. Сценарий приёмки пилота на двоих

**Версия:** 2.0 · **Дата:** 2026-11-01 · **Статус:** DRAFT. Сценарий написан до первой сборки; ожидаемые результаты следуют из спецификаций [04](04_SYSTEMS_SPEC.md) и тестов [08](08_QA_AND_ACCEPTANCE.md), а не из наблюдения за игрой.

Играют двое: **A** — хост (Listen Server), **B** — клиент. Сессия 60–90 минут. Запускайте с `-ScavarFreshWorld`, если нужен чистый мир. Логи — `Saved/Logs/SCAVAR.log` у каждого; при ошибке приложите оба.

| 0.2 | В логе хоста найти `Loaded balance tables`, `World inventory ready`, `Loot economy ready`, `AI director ready`, `World save ready` | Пять строк без `Error` |

## Известные ограничения пилота

1. Окна инвентаря нет: список на канвасе, использование цифрами.
2. Безопасный карман (2×2) управляется клавишами (Z + цифра) без наглядной сетки; после появления окна инвентаря он станет перетаскиванием.
3. Попадание мгновенное, зоны определяются высотой попадания, откат хитбоксов нет — [ADR-027](10_DECISIONS_AND_LEGACY_MAP.md).
4. Торговли, заданий, крафта, погоды (кроме смены дня и ночи) нет — [ADR-026](10_DECISIONS_AND_LEGACY_MAP.md).
5. Если не получилось определить аккаунт, ключом служит имя игрока: запускайте двух тестировщиков с разными именами (`-Name=A`, `-Name=B` или разные имена профилей), иначе они разделят один инвентарь.
